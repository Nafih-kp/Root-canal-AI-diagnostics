================================================================================
KNOWLEDGE DISTILLATION - QUICK START GUIDE
================================================================================

This file provides quick commands to run the knowledge distillation pipeline.

================================================================================
1. COMPLETE PIPELINE (Recommended for first run)
================================================================================

Run all stages: teacher training → student training → evaluation → analysis

Command:
  python run_distillation_pipeline.py --stage all

Or Windows:
  RUN_DISTILLATION.bat  [then select option 1]

Duration: 6-12 hours (with GPU)

================================================================================
2. INDIVIDUAL STAGES (For targeted execution)
================================================================================

Train Teacher Model Only:
  python run_distillation_pipeline.py --stage teacher
  Duration: 4-8 hours

Train Student with Distillation:
  python run_distillation_pipeline.py --stage student
  Duration: 2-4 hours
  (Requires trained teacher model)

Evaluate All Models:
  python run_distillation_pipeline.py --stage evaluate
  Duration: 1-2 hours
  (Requires trained models)

Run Comparative Analysis:
  python run_distillation_pipeline.py --stage analyze
  Duration: 30-45 minutes

Start Inference Server:
  python run_distillation_pipeline.py --stage inference
  Or: python inference_server.py

================================================================================
3. INFERENCE SERVER MANAGEMENT
================================================================================

Start Server:
  python inference_server.py

Check Server Status:
  curl http://localhost:5000/health

List Available Models:
  curl http://localhost:5000/models

Switch to Different Model:
  curl -X POST http://localhost:5000/models/student_distilled
  curl -X POST http://localhost:5000/models/teacher_model
  curl -X POST http://localhost:5000/models/student_baseline

Test Detection Endpoint:
  POST http://localhost:5000/detect
  Content-Type: application/json
  Body: {"image": "data:image/jpeg;base64,..."}

5. MODEL CONFIGURATION
================================================================================

Edit model_config.json to:
  - Change default model
  - Add/remove models
  - Adjust preprocessing settings
  - Modify inference parameters

Default Model: student_distilled (YOLOv8n with knowledge distillation)

Available Models:
  ✓ student_baseline      - Original YOLOv8n
  ✓ student_distilled     - YOLOv8n with distillation (RECOMMENDED)
  ✓ teacher_model         - YOLOv8m (reference)
  ✓ filtered_baseline     - YOLOv8n trained on filtered images

================================================================================
6. EXPECTED RESULTS
================================================================================

Teacher Model (YOLOv8m):
  - Precision: ~0.88
  - Recall: ~0.86
  - mAP50: ~0.87
  - Parameters: 25.9M

Student with Distillation (YOLOv8n):
  - Precision: ~0.85-0.87
  - Recall: ~0.83-0.85
  - mAP50: ~0.84-0.86
  - Parameters: 6.9M (73% reduction)

Distillation Benefit:
  - 2-5% accuracy improvement over baseline student
  - ~40-50% faster inference than teacher

================================================================================
7. TROUBLESHOOTING
================================================================================

Model Loading Issues:
  → Check model paths in model_config.json
  → Verify file permissions
  → Check CUDA/PyTorch compatibility

Out of Memory During Training:
  → Reduce batch size in YOLO training config
  → Use gradient accumulation
  → Reduce image size (imgsz parameter)

Poor Distillation Results:
  → Train for more epochs
  → Adjust temperature (try 3.0-5.0)
  → Adjust alpha weight (try 0.5-0.9)
  → Verify teacher model quality

Inference Server Won't Start:
  → Check port 5000 is available
  → Verify model files exist
  → Check firewall settings
  → Review server logs for errors

================================================================================
10. SUPPORT & OPTIMIZATION
================================================================================

GPU Usage:
  - Training is much faster with GPU (NVIDIA/CUDA recommended)
  - CPU training will be very slow (not recommended)
  - Check GPU: nvidia-smi

Optimization Tips:
  - Use batch processing for multiple images
  - Cache preprocessing operations if possible
  - Monitor memory usage during training
  - Save checkpoint models periodically

Performance Tuning:
  - Adjust distillation temperature (3.0-5.0)
  - Adjust alpha weight (0.5-0.9)
  - Modify learning rate schedule
  - Try different optimizers (Adam, SGD)
