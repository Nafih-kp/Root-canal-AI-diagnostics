EXECUTIVE SUMMARY
============================================================

This report provides a comprehensive analysis of the knowledge distillation
pipeline implementation for dental X-ray classification. The pipeline employs
a teacher-student architecture where a large YOLOv8m model (teacher) transfers
knowledge to a compact YOLOv8n model (student) for efficient deployment.

KEY OBJECTIVES:
1. Quantify the impact of image filtering on model performance
2. Measure accuracy improvement from knowledge distillation
3. Demonstrate model efficiency gains
4. Validate the approach for clinical deployment

============================================================

1.1 KNOWLEDGE DISTILLATION ARCHITECTURE
---------------------------------------------------
The pipeline consists of three distinct models:

MODEL 1: TEACHER (YOLOv8m)
  Purpose: Serves as the knowledge source
  Architecture: YOLOv8 Medium
  Parameters: 25,858,636

MODEL 3: STUDENT DISTILLED (YOLOv8n + Knowledge Distillation)
  Purpose: Lightweight model enhanced by teacher knowledge
  Architecture: YOLOv8 Nano
  Parameters: 3,011,628
  File Size: 5.96 MB
  Training: YOLO + KL-divergence distillation loss
  Role: Production model combining efficiency with accuracy

1.2 DISTILLATION LOSS FUNCTION
---------------------------------------------------
The training objective combines task loss and distillation loss:

Total Loss = α × Task Loss + (1 - α) × Distillation Loss

Where:
  α (alpha): 0.7 - Weight for the standard YOLO detection loss
  Temperature: 4.0 - Controls softness of soft target probabilities
  
Distillation Loss = KL-Divergence(Student, Teacher)
Task Loss = YOLO Detection Loss (bbox + conf + class losses)

10.4 METRICS EXPLANATION
---------------------------------------------------
Precision: TP / (TP + FP) - "Of detected root canals, how many were correct?"
Recall:    TP / (TP + FN) - "Of actual root canals, how many were detected?"
mAP50:     Mean Average Precision at 50% IoU threshold
mAP50-95:  Mean Average Precision at IoU [0.50:0.05:0.95]
F1-Score:  2 * (Precision * Recall) / (Precision + Recall)

Sensitivity: TP / (TP + FN) - True positive rate (same as Recall)
Specificity: TN / (TN + FP) - True negative rate

Where:
  TP = True Positive (correctly detected)
  TN = True Negative (correctly rejected)
  FP = False Positive (incorrectly detected)
  FN = False Negative (missed detection)
